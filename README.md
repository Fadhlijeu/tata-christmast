# ASCII Christmas Tree

A full-screen, procedural 3D Christmas tree rendered in ASCII characters.

## Features

- Layered fir branches with richer green shading
- Four-strand gold garland
- Red, gold, and silver ornaments
- Warm animated fairy lights
- Wrapped presents, falling snow, and a glowing star
- Full-length soundtrack loop

## Run

Open the GitHub Pages site in a modern browser. Tap or click anywhere once to start the soundtrack; the browser requires a user gesture before allowing audible playback. The full MP3 loops continuously.

## Implementation

Plain HTML, CSS, JavaScript, and Canvas 2D. No build step or external audio service is required.

Deployment is published from the `main` branch with GitHub Actions.
